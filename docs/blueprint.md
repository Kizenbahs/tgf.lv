# **App Name**: ConstructPro

## Core Features:

- Engaging Hero Section: Hero section with a large background image, title, description, and a call-to-action button for immediate user engagement.
- Service Showcase: Display key service areas with visual elements similar to the reference image. Interactive elements on the home page with details on each service.
- Concise Footer: Compact and informative footer containing copyright information and the current year.
- AI Project Visualizer: AI-powered 'Project Visualizer' tool. Input project details, and the tool provides a concept visualization.
- Standard Header Navigation: A right-aligned header menu providing navigation links. Left-aligned logo.
- Enhanced UI animations: Motion Framer animations for transitions and element appearance, along with shadcn UI components, enhance visual appeal.

## Style Guidelines:

- Primary color: Use a vibrant yellow (#FFC107) to highlight key interactive elements, ensuring they capture user attention against the dark backdrop.
- Background color: A very light gray (#F0F0F0) will be used for primary background to keep readability. Additional grayscale tones, ranging from #333333 (dark gray) to #FFFFFF (white), create depth and emphasize the structural design elements of the site.
- Accent color: Analogous to yellow, an orange hue (#FF9800) will serve as the accent color. Employ this in secondary buttons and interactive features, achieving a cohesive and lively interface.
- Font pairing: 'Space Grotesk' (sans-serif) for headlines, and 'Inter' (sans-serif) for body text. Note: currently only Google Fonts are supported.
- A hero section image is at the top. Followed by services, the other section should have a clean grid. The menu should be on the header right.
- Subtle motion framer animations for transitions.
